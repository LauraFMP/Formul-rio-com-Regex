# 📋 Formulário de Cadastro

Projeto desenvolvido em **HTML, CSS e JavaScript** com o objetivo de criar um formulário de cadastro com validações, máscaras de entrada e feedback visual para os campos.

## ✨ Funcionalidades

* Cadastro de dados pessoais e contatos
* Máscara automática para:

  * 📅 Data de nascimento
  * 🪪 CPF
  * 📞 Telefone
  * 📍 CEP
* Validação de campos utilizando **Regex**
* Validação nativa do HTML
* Feedback visual para campos válidos e inválidos
* Modal de confirmação após o envio
* Opção para preencher o formulário novamente
* Navegação por teclado e suporte básico à acessibilidade

## 🛠️ Tecnologias

* HTML5
* CSS3
* JavaScript
* Regular Expressions (Regex)

## 📂 Estrutura

```text
📦 formulario-cadastro
 └── index.html
```

## 🚀 Como executar

1. Clone este repositório:

```bash
git clone URL_DO_REPOSITORIO
```

2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` em um navegador.

Não é necessário instalar dependências.

## 🎯 Objetivo

O projeto foi desenvolvido para praticar **formulários HTML, validação de dados, expressões regulares (Regex), máscaras de entrada e manipulação do DOM com JavaScript**.
